# 仅检测床上患者的 CT 姿势监测版本

[English](readme.md)

当前患者检测版本位于 `top_camera/`，原先包含周围场景检查的版本保存在 `archive/top_camera/`。网页继续全英文，两种 CT 方案、持续采集、蓝框和复位指导均保留。

## 启动与操作

双击本目录的 `start_demo.bat`，打开 [http://localhost:8001](http://localhost:8001)。使用本目录的 `.venv/` Python 环境。代码、模型和运行记录为本版本独立保存。换电脑可通过本目录 `setup_demo.ps1` 建立环境。

1. 点击 **Calibrate**，采集床面预览。自动生成黄色床框，支持亮色、深色床垫及画面中较短的床面；最好无遮挡，不准确时手动标出四角。识别失败时不会虚构床框。不要求房间清空，也不检查背景稳定性。
2. 确认黄色床框及头端，点击 **Use bed outline**。
3. 选择 **Head CT**（双臂体侧）或 **Chest / Abdomen / Pelvis CT**（双臂头顶）。
4. 默认每秒采集并判断一帧，前三帧确认短时稳定性。第一张照片的分析结果返回前只显示中性的启动提示；结果返回后才显示绿色 **Within criteria** 或红色 **Outside criteria**，图片下方显示英文复位指导。黄色床框仅在床面校准和确认时显示；人体姿势监测仅显示蓝色问题框。
5. 点击另一种 CT 按钮切换方案；点击 **Stop monitoring** 停止。

## 与原版的区别

- 不建立空房间背景基准，不执行杂物差分，也不检查人体分割面积。
- 最终结果仅依赖床上患者的可见性、相对床面位置、所选方案手臂姿势、腿部、躺平线索和短时稳定性。
- 床外人员按检测到的髋中点位置过滤；同一床面区域内出现另一名独立且可信的人仍会拦截。床面区域有少量容差边界，不能代替身份识别。
- 没有红色杂物框或忽略区域设置。
- 仍需确认床框及头端。重启、换摄像头/分辨率、移动床或摄像头后重新校准。
- 背景变化本身不会导致不通过；若物品遮住患者，仍可能因关键点不可见或识别不可靠而不通过。

结果接口保留布尔字段 `ready`、`pose_ready`，状态文字使用 Within criteria / Outside criteria，返回 `scene_checked: false`；不再返回场景合格判定或红色杂物框。结果超过三秒无更新会失效，隐藏页面会停止监测。

## 测试与边界

在本目录运行 `.\.venv\Scripts\python.exe -m unittest -v test_patient_only.py`。

测试使用合成关键点与模拟检测，不能代表真实摄像头或临床准确率。单目 RGB 仍不能可靠确认全部三维姿势、身体贴床及仰卧/俯卧；本版本不连接 ACU 或扫描启动联锁。

## 手放胸前的检查

增加肩至髋之间的二维躯干区域判断：手腕或可信且靠近手腕的手指点落在该区域内时，不接受为体侧放臂，可拦截双手各在胸部一侧、单手放胸前等情况。正常体侧放臂、头顶举臂和一定旋转仍允许。此检查依赖人体关键点，关键点误识别或遮挡仍可能导致误判。

## 白天光照下的床框识别

校准时结合轮廓候选和成对长床沿，优先选择有连续明亮床面的候选，降低黑色地垫的评分；用有方向的边缘细调床沿及床头床尾，避免跟随地面反光或附近柜体。保留深色床垫的轮廓后备识别。生产代码没有写死本房间的床坐标。提供的白天截图已加入回归测试，覆盖曝光变化、缓慢阴影和轻微旋转；仍需人工确认床框和头端。
